# Research behind the mascots' materials and light

These are working reports, written by research agents for the people changing the renderer. The summary of what was
used, and what it rests on, is in [../MATERIALS.md](../MATERIALS.md).

| report | what it is | how it was made |
|---|---|---|
| [reference-texture.md](reference-texture.md) | a forensic study of the reference characters' surface (strand sizes, grain, the pale rim, tones, shadows, the light), our renders measured the same way, and a recipe | the measurements (section 2) are the first researcher's; they were cut off, and the rest was written from their saved log and scripts by a second agent, which says so section by section. No rendering literature was read for it. |
| [natural-light.md](natural-light.md) | natural light for a small soft object on a plain page: about 27 sources, a rig fitted numerically to the reference's tones | the first researcher was cut off before writing; the report was finished from their log, scripts and saved sources by a second agent, which re-ran the calculations and marks which numbers are whose. "Rig E" is the rig in the code. |
| [cotton.md](cotton.md) | cloth reflectance and knit structure for smooth cotton: 22 sources read | written in one piece by one researcher, before cotton became a brushed nap |

The reports name files in a scratch folder (crops, scripts, renders) that is not part of this repository, and they
describe the renderer as it was when they were written, before the changes they led to. None of the reference's
pictures are in this repository.

Reports on bouclé, elastane, sugar, clay and fibre shading were started twice and cut off by a usage limit before
anything was written.
