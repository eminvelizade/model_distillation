# ModelLab web UI

Before adding or changing anything in this UI, read [DESIGN.md](DESIGN.md) and follow it: theme tokens instead of
raw colours, the existing components in `src/ui.tsx` and `src/components/`, the motion vocabulary, and the
sparkle budget. No purple, pink or indigo; no remote assets.

Run `npm run build` after UI changes and commit the updated `dist/` (the Python app serves it).
